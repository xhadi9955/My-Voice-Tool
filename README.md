## Features

| Feature | Description |
|--------|-------------|
| **Text to Speech** | High-quality TTS with voice design presets |
| **Voice Cloning** | Clone a voice from a short reference clip (3–10s) |
| **600+ Languages** | Broad multilingual coverage |
| **SRT Subtitles** | Optional subtitle generation |
| **MP3 Export** | Download at 320 kbps |
| **Emotion Tags** | `[laughter]`, `[sigh]`, and more |

## Quick Start

1. Click **[Open in Colab](https://colab.research.google.com/github/xhadi9955/My-Voice-Tool/blob/main/X_HADI_Colab.ipynb)**
2. Runtime → Change runtime type → **GPU (T4)**
3. Run **Step 1** (enter your registered Gmail)
4. Run **Step 2** — wait 2–3 minutes on first run for model download
5. Open the public **`.gradio.live`** link and use the studio
